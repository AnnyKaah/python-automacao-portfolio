## 🧠 Como resolvo os exercícios

Quando encontro um problema novo, sigo este processo antes de escrever qualquer linha:

1. Ler o enunciado com calma e entender o que é pedido
2. Escrever em português o que o programa precisa fazer
3. Identificar quais conceitos Python vou precisar
4. Escrever pseudocódigo antes de codar
5. Traduzir para Python, linha a linha
6. Testar com casos diferentes — inclusive os "errados"
7. Documentar o que aprendi com aquele exercício

|------|-------------|-----------------|
| `TypeError` | `in` com número em vez de string | Verifico o tipo antes |
